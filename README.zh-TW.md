# Xeltri

> **Xeltri：一塊異質開發板。**
> X = 異質混核，el = electronics（電子），tri = 三核（MPU + MCU + FPGA）。
> 這是一塊把 FPGA、MPU 與 MCU 整合在同一系統上的板子。(開發中)

#### 英文版請見 [README.md](README.md)。

### 專案概述
本專案是專門為了桌面型貼片機打造的主控板，主控採用STM32H745XIH6(MCU)、XC7A35T-2CSG325C(FPGA)以及V851S(MPU)三核心協同工作(已確定)，外部擴充介面有PCIE2.1*2(位於PCIE *4插槽，連接到FPGA)、micro SD卡槽，其餘待定

### 開發板基礎架構以及核心選型原因
Xeltri開發板是由STM32H745XIH6(MCU)、XC7A35T-2CSG325C(FPGA)以及V851S(MPU)為核心打造。我會採用這三顆核心是因為我打算挑戰純光學對位+視覺相機來對位，在貼低複雜度的元件(0805、0402等封裝)時使用純光學對位，預到高複雜度的元件使用視覺相機來對位(類似openCV)，並且我還想要上/下視相機等等搭配端測AI來做機器狀態檢測，這就是我為什麼要用V851S的原因。會用純光學來貼低複雜度元件是因為我想要工業飛拍的速度但是要達到這速度需要的視覺方案硬體實在太貴，但是使用純光學對位可以便宜許多，可這對即時性有一定需求，又因為我的機器想做成類似箱型coreXY的形狀提供更少的底面積(像voron打印機那樣)，這導制會有許多複雜的結構與需要控制的步進馬達，而閉環步進馬達(閉環控制器位於馬達底部的)對我來說又太貴且低價位響應不夠快，而FPGA可以解決並且還可以做更多的事(我想要最終的機器是強悍而不只是堪用而已)，所以最終才會有這三個核心的組合。
