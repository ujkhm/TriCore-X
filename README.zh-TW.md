# Xeltri

> **Xeltri：一塊異質開發板。**
> X = 異質混核，el = electronics（電子），tri = 三核（MPU + MCU + FPGA）。
> 這是一塊把 FPGA、MPU 與 MCU 整合在同一系統上的板子。
